# Cosplay Event Manager

A Spring Boot REST API for managing cosplay events and costumes.

# Tech Stack
- Java
- Spring Boot
- MySQL
- JPA/Hibernate

# Endpoints

# Event
- POST /cosplay/add/event
- GET /cosplay/event/list
- GET /cosplay/event/list/{id}
- PUT /cosplay/event/update/{id}
- DELETE /cosplay/event/delete/{id}

# Costume
- POST /cosplay/add/costume
- GET /cosplay/costume/list/{id}
